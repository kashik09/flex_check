# flex_check

A basic webpage demonstrating the use of CSS Flexbox for layout design.

## Description

This project showcases a responsive webpage layout utilizing CSS Flexbox. It includes:

- **index.html**: The main HTML file containing the structure of the webpage.
- **style.css**: The CSS file styling the webpage with features like flexboxes.
- **images/**: A directory containing images used in the webpage.

## Features

- Responsive design that adapts to various screen sizes.
- Clean and modern layout achieved with flexboxes.
- Organized file structure for easy navigation and maintenance.
